# Adidas US Sales Dashboard

Professional Streamlit dashboard using the Adidas US Sales dataset.

## Features
- Total Sales KPI
- Total Profit KPI
- Units Sold KPI
- Sales by Region
- Sales by Product
- Monthly Sales Trend
- Retailer Contribution

## Dataset
Included: data/Adidas_US_Sales.xlsx

## Run

pip install -r requirements.txt

streamlit run app.py
